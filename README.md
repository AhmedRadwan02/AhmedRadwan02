I work in **responsible AI and multimodal understanding**. When something works, I like to ask “why?” and then “what if?”

## things you can check

- **[SONIC-O1](https://vectorinstitute.github.io/sonic-o1/)** · A model can summarize a conversation. Can it point to the moment someone said something? We built a benchmark around real conversations to test that. [Explore the dataset](https://huggingface.co/datasets/vector-institute/sonic-o1)
- **[MARS](https://vectorinstitute.github.io/mars/)** · When our detector flags a video as fake, you can see which frames and patches tipped it off. MARScope lets you try it on a clip of your own. [See the demo](https://vectorinstitute.github.io/mars/#demo)
- **[UnBias-Plus](https://github.com/VectorInstitute/unbias-plus)** · Paste in a paragraph. It flags potentially biased wording, explains why, and suggests an edit you can judge for yourself. [Try it](https://unbias-plus.vectorinstitute.ai/)

What happens when you show a model a face and ask whether to hire that person? We tested that in **[FairLens](https://github.com/VectorInstitute/fairlens)**. [Read the paper](https://arxiv.org/abs/2609.01691)
